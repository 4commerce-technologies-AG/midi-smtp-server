# Security Policy

In case of an overall API compatibility we just support the latest release
with security updates.

#### Supported Versions

| Version | Supported                      |
| ------- | ------------------------------ |
| 3.x.y   | Yes                            |
| <= 3.2  | Critical security issues only  |
|         | EOL end of 2026                |
| <  3.x  | No                             |

#### Supported Ruby

| Version | Supported                      |
| ------- | ------------------------------ |
| 4.0.y   | Yes                            |
| 3.4.y   | Yes                            |
| 3.3.y   | Yes                            |
| <= 3.2  | No, but functional down to 2.7 |

#### Reporting a Vulnerability

In case of a vulnerability please report a security advisory.
